# RISC-V Disassembler 

A simple RISC-V Disassembler adhering to the RISC-V ISA. Decodes elf files to disasm files, showing human-readable assembly. Prints all the mnemonics with all the operands, including labels.

Two examples are provided in samples folder. The program.elf file is the input. The output should be the same as in the program.disasm file.
